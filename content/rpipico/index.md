# Raspberry Pi Pico (RP2040)

.NET **nanoFramework** supports the Raspberry Pi Pico family based on the RP2040 microcontroller.

## Articles in this section

- [RP2040 features and support](rp2040.md)
- [Raspberry Pi Pico (RP2040 and RP2040 W) pin out](rp2040_pin_out.md)

## Flashing firmware

Use [nano Firmware Flasher (nanoff)](https://github.com/nanoframework/nanoFirmwareFlasher) to flash the firmware. See the [Raspberry Pi Pico usage examples](https://github.com/nanoframework/nanoFirmwareFlasher#raspberry-pi-pico-usage-examples) for the exact commands.
