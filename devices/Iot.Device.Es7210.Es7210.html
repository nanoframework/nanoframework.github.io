Driver for the Everest Semiconductor ES7210 4-channel audio ADC (microphone capture codec).

public class Es7210
Inheritance
object
Es7210

Remarks

This binding covers the I2C control plane only. It configures the codec (clocking, microphone selection, gain, mute and power state) for a two-microphone (MIC1 + MIC2) I2S capture setup in slave mode. The captured PCM audio samples are streamed out over I2S using System.Device.I2s and are not handled by this class. The register sequences are ported from the Espressif esp_codec_dev component.

The gain code, from MinMicGain (0 dB) to MaxMicGain (37.5 dB). Each step up to code 11 is roughly 3 dB. Values above MaxMicGain are clamped.
