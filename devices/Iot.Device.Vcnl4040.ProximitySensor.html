ActiveForceMode

Gets or sets a value indicating whether active force mode is enabled. When the sensor is operated in Active Force Mode, an explicit request for a measurement is required before a current measurement value can be read. This is in contrast to normal operation, where measurements are continuous. This significantly reduces power consumption, as the IR LED is only activated for each individual measurement. Important: In Active Force Mode, the interrupt function is not available, as no measurement is performed, and therefore, threshold checks are not possible.

public bool ActiveForceMode { get; set; }
