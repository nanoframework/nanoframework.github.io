Driver for the Everest Semiconductor ES8156 low-power stereo audio DAC (playback codec).

public class Es8156
Inheritance
object
Es8156

Remarks

This binding covers the I2C control plane only. It configures the codec (clocking, serial data format, volume, mute and power state). The actual PCM audio samples are streamed over I2S and are not handled by this class. The register sequences are ported from the Espressif esp_codec_dev component and should be validated on real hardware.

Remarks

This runs the ES8156 initialization register sequence (slave mode, I2S data format). After calling this method the codec is powered up and ready to receive an I2S stream. Use Volume to set the output level and Muted to mute.
