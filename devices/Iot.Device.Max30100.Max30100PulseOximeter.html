Remarks

The default oxygen-saturation calculation uses an uncalibrated ratio-of-ratios approximation. Results are for experimentation only and must not be used for medical purposes.

CalibrateOxygenSaturation(double[], double[])

Fits oxygen-saturation calibration coefficients from paired ratio and reference measurements.

public void CalibrateOxygenSaturation(double[] ratios, double[] referenceOxygenSaturations)

Parameters

ratios double[]

Stable RatioOfRatios measurements.

referenceOxygenSaturations double[]

Simultaneous reference oxygen-saturation percentages.

Exceptions

ArgumentNullException

Either array is null.

ArgumentException

The arrays have different lengths, contain fewer than two points, all ratios are equal, or the fitted slope is not negative.

ArgumentOutOfRangeException

A ratio is outside zero through 10, or a reference oxygen-saturation value is outside zero through 100.
