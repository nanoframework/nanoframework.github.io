int

Remarks

Common values returned by the ESP-IDF ESP-NOW APIs:

  • ESP-NOW is not initialized (ESP_ERR_ESPNOW_NOT_INIT = 0x3065).
  • Invalid argument (ESP_ERR_ESPNOW_ARG = 0x3066).
  • Out of memory (ESP_ERR_ESPNOW_NO_MEM = 0x3067).
  • ESP-NOW peer list is full (ESP_ERR_ESPNOW_FULL = 0x3068).
  • ESP-NOW peer is not found (ESP_ERR_ESPNOW_NOT_FOUND = 0x3069).
  • Internal error (ESP_ERR_ESPNOW_INTERNAL = 0x306A).
  • ESP-NOW peer has already been added (ESP_ERR_ESPNOW_EXIST = 0x306B).
  • Interface error, Wi-Fi and ESP-NOW must run on the same interface (ESP_ERR_ESPNOW_IF = 0x306C).
  • Channel error (ESP_ERR_ESPNOW_CHAN = 0x306D).
  • Out of memory, generic ESP-IDF error (ESP_ERR_NO_MEM = 0x101).
  • Invalid state, e.g. the controller is already initialized, generic ESP-IDF error (ESP_ERR_INVALID_STATE = 0x103).
