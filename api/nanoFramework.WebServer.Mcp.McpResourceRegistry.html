DiscoverResources(object[])

Discovers MCP resources by scanning the provided object instances for methods decorated with the McpServerResourceAttribute. Instance methods are invoked against the object they were discovered on, allowing live device objects to expose resources. This overload is additive and can be called in addition to the static DiscoverResources(Type[]) discovery.

public static void DiscoverResources(object[] resourceInstances)

Parameters

resourceInstances object[]

An array of object instances to scan for MCP resources.

DiscoverResources(object[], string[])

Discovers MCP resources on the provided object instances, prepending an optional per-instance URI prefix to every discovered resource URI so that several instances of the same type can be registered without URI collisions. This overload is additive and can be called in addition to the static DiscoverResources(Type[]) discovery.

public static void DiscoverResources(object[] resourceInstances, string[] uriPrefixes)

Parameters

resourceInstances object[]

An array of object instances to scan for MCP resources.

uriPrefixes string[]

An optional parallel array of relative URI prefixes; a null or empty entry means no prefix. May be null to apply no prefixes.
