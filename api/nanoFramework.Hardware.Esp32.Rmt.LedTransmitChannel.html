Parameters

pinNumber int

GPIO output pin number.

T0L ushort

Data transfer time in ticks for bit 0 low part (number of 100ns ticks).

T0H ushort

Data transfer time in ticks for bit 0 high part (number of 100ns ticks).

T1L ushort

Data transfer time in ticks for bit 1 low part (number of 100ns ticks).

T1H ushort

Data transfer time in ticks for bit 1 high part (number of 100ns ticks).

ResetTime ushort

Data transfer time in ticks for reset (number of 100ns ticks).

Remarks

Used for creating led strip channels with different timings to standard led strip types. For standard types use LedTransmitChannel(int, LedType)
