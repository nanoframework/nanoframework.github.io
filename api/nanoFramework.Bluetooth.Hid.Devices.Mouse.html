Move(sbyte, sbyte)

Simulates moving a mouse in a specific direction using the coordinates system.

public void Move(sbyte x, sbyte y)

Parameters

x sbyte

X-Axis value.

y sbyte

Y-Axis value.

Remarks

x & y are relative values to the last cursor position. This means if the cursor is at (x: 500, y: 500) and the Move(sbyte, sbyte) method is called with X = 100, Y = 50 then the new cursor position will be (X: 600, Y: 550).
